# 🎯 Hangman Game (Python)

A classic terminal-based Hangman game built using Python. Test your vocabulary by guessing hidden words one letter at a time before you run out of attempts!

---

## ✨ Features

- 🔤 **Randomized Word Selection:** Picks words dynamically for a unique experience every round.
- 🎨 **Visual Hangman Stages:** ASCII art updates visually with every incorrect guess.
- 🚫 **Duplicate Input Handling:** Warns you if you repeat a letter without losing a turn.
- 📊 **Interactive Gameplay:** Displays remaining attempts and correctly guessed letters after each move.
